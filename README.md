**Command Pattern Calculator with DevOps Enhancements**
**Overview**
This project implements a command-line calculator application using the Command Design Pattern and Plugin Architecture. The application has been enhanced with DevOps features, including logging, environment variables, and GitHub Actions for continuous integration, making it suitable for production environments.

**Features**
Command Pattern: A structured approach to execute different operations as commands. 
Plugin Architecture: Dynamically loads commands as plugins, allowing for easy extensions. 
Logging: Comprehensive logging for tracking user interactions and errors, essential for monitoring and debugging. 
Environment Variables: Securely handles sensitive information through environment variables, ensuring API keys and passwords are not exposed. 
Continuous Integration: Utilizes GitHub Actions to automatically run tests upon pushing changes to the main branch. User Input Validation: Validates user input to prevent errors and enhance the user experience.
